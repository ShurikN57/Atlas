# Atlas

Prototype web d’assistance à l’instruction des dispositifs de publicité, enseignes et préenseignes.

## v0.1

Cette première version sert à valider l’architecture :

- saisie d’une localisation ;
- choix du type de dispositif ;
- choix de l’implantation ;
- saisie des dimensions ;
- calcul automatique de la surface ;
- premières règles de démonstration pour ZE2, ZE3 et ZP5-A ;
- alerte spécifique pour dispositifs numériques et visibilité depuis une autoroute / voie express.

## Important

Le référentiel réglementaire de la v0.1 est volontairement incomplet. Le résultat affiché est une pré-analyse et ne constitue pas une décision réglementaire.

## Prochaines étapes

1. intégrer le RLPi complet de l’Eurométropole de Metz ;
2. séparer les règles dans un référentiel de données versionné ;
3. intégrer le zonage cartographique ;
4. géocoder automatiquement les adresses ;
5. ajouter les règles nationales du Code de l’environnement et du Code de la route ;
6. générer une fiche d’instruction exportable.
